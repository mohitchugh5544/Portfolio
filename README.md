# Mohit Chugh — Personal Portfolio

A Linear/Raycast-inspired **Dark Mode Bento Grid Portfolio** built with **Next.js 15, TypeScript, Tailwind CSS, and Framer Motion**.

## Quick Start

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## How to Add More Projects or Edit Content

All portfolio data lives in a single file:
- `src/data/portfolio.ts`

To add a new project later, simply append a new object to the `projects` array in `src/data/portfolio.ts`. To update the live URL of **Riya Dresses** or **Fitness+ Vision**, edit the `liveUrl` and `githubUrl` fields in `src/data/portfolio.ts`.
